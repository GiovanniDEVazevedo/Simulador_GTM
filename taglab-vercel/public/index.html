4. Configurar GTM, GA4 e Ads

Baixar roteiro completo
UPD no GA4: primeiro teste
  1. No site, use modo GTM. No GA4 de teste, confira a vinculação com Google Ads exigida pela documentação atual, habilite a coleta de dados fornecidos pelo usuário e as capacidades de UPD da Google tag, revisando os termos. Use coleta por código nesta prática.
  2. No GTM, crie a variável de camada de dados DLV - lab_user_data, nome lab_user_data, versão 2.
  3. Crie uma variável JavaScript personalizado JS - UPD Lab com o código abaixo. Crie uma variável Dados fornecidos pelo usuário → Código usando essa variável como fonte.
  4. Crie uma tag de evento GA4 com ID G-K3P3QWNJ38 (ou seu fluxo de teste), evento generate_lead, parâmetro especial user_data apontando para a variável de Dados fornecidos pelo usuário, e debug_mode = true.
  5. Use acionador Evento personalizado, nome exato lab_upd_lead. A Google tag base usa Inicialização — Todas as páginas.
  6. Conceda analytics_storage e ad_user_data na aba Consentimento, conecte o Preview e envie o caso. Na linha do evento, confira variável e tag disparada.
function () {
  var data = {{DLV - lab_user_data}};
  return data || undefined;
}

Não crie dimensões personalizadas para e-mail, telefone ou hashes. user_data é um campo especial, mapeado com a variável apropriada.

EC: compra no GA4 e caminho opcional Google Ads

Para GA4, crie outra tag de evento: purchase, acionador lab_ec_purchase, dados de e-commerce pelo dataLayer e a mesma variável especial user_data. Para esta compra de teste, o valor é R$ 49,90 e cada novo caso gera um transaction_id.

Para uma tag de conversão do Google Ads, é necessário criar/configurar uma ação de conversão de teste e usar o Conversion ID e Label fornecidos pela conta. Configure os dados fornecidos pelo usuário na Google tag/tag de conversão conforme sua interface, usando a variável do laboratório. Acione apenas em lab_ec_purchase, mapeando valor, moeda e ID da transação. Veja o roteiro completo e a documentação oficial.

A preparação local de UPD pode ser praticada sem conectar contas. Para validar coleta e EC no GA4, cumpra os pré-requisitos atuais, incluindo vínculo com Ads; ECL também precisa do fluxo de resultado offline. Não trate o simples envio de um formulário como uma importação de conversão offline.

    CONSENT MODE V2

    Controle a permissão de coleta

    O padrão inicial é denied. Os controles enviam comandos reais de consentimento antes do carregamento das tags.

    Simulação técnica de consentimento. Valide o estado no Tag Assistant; isto não substitui uma CMP de produção.

    Conectar sua implementação

    O padrão é o contêiner GTM-KW59VB3X. Para testar acionadores, use o modo Google Tag Manager. GA4 direto com G-K3P3QWNJ38 é uma alternativa; ele não carrega o seu contêiner GTM. A escolha fica apenas neste navegador.

    Inicialização do GTM: confira o evento Inicialização no Preview do contêiner escolhido, no Tag Assistant. O painel local mostra pushes no dataLayer e pode não listar eventos internos como gtm.init. Use o acionador nativo Inicialização – Todas as páginas para a Google tag; não crie um push manual de gtm.init.
    GTG precisa de infraestrutura. Este site aceita o caminho first-party do gateway, mas não cria o roteamento no domínio. Configure o GTG em seu domínio/CDN e depois informe o caminho. Não confunda GTG com um contêiner server-side.

    Validação real

    O monitor comprova o push no dataLayer. Confirme o disparo da tag no Preview do GTM e o recebimento no DebugView do GA4. Um script carregado não comprova entrega de eventos.

    Abrir Tag Assistant ↗

    Plano de mensuração

    No modo GTM: crie uma Google tag com seu G-ID e acionador All Pages. Crie tags de evento GA4 para os eventos abaixo, com acionadores de Evento personalizado. Ative o envio de dados de e-commerce a partir do dataLayer.

    page_view, form_start, form_submit, click, scroll e eventos de vídeo também podem vir da medição otimizada. Escolha uma estratégia por evento para evitar duplicação. O GA4 direto usa send_page_view: false, pois este laboratório envia page_view explicitamente. No fluxo GA4, desative também visualizações por mudanças no histórico na Medição otimizada para evitar duplicação.

    Checklist de validação

    1. Configure seu GTM ou GA4 na aba Configuração.
    2. Aceite analytics_storage na aba Consentimento.
    3. Abra o Preview do GTM e conecte esta URL.
    4. Faça o funil: produto → carrinho → checkout → entrega → pagamento → compra.
